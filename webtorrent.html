Module · module webtorrent · layer overlay · v0.0.1 · IRI https://torrent-schema.github.io/webtorrent

BitTorrent in a browser. A browser cannot open a TCP or UDP socket, so it cannot reach a tracker, the DHT, or a peer the usual way; WebTorrent changes exactly two things and nothing else: peers are found and introduced through a tracker spoken over WebSockets in JSON (this module), and the connection between two peers is a WebRTC data channel — over which the peer wire protocol of the wire module runs byte for byte unchanged. This protocol has no BEP; it is what the WebTorrent implementation does, written down here from a captured exchange with tracker.openwebtorrent.com.
