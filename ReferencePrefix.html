Enumeration · module nostr · IRI https://torrent-schema.github.io/ReferencePrefix

The prefixes an 'i' tag may carry, each naming an external database the content is listed in: ['i', 'imdb:tt15239678']. Where a database holds several media types a second segment names the type: 'tmdb:movie:693134'. The URL mapping is a guide, not part of the NIP. Events in the wild carry prefixes beyond this list ('tpb', 'nyaa', from mirrors of those indexes); the codec reports them as unknown, not as errors.
