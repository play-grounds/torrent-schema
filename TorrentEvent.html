Struct · module nostr · encoding nostrTag · kind 2003 · 7 fields · IRI https://torrent-schema.github.io/TorrentEvent

A torrent listing, kind 2003: the tags of a NostrEvent read as fields. Carries what a magnet link carries — the v1 infohash, a name, trackers — plus the file list with sizes, external references and topics for search. Carries nothing that would let the info dictionary be rebuilt: no piece length, no pieces, no v2 root; a client fetches those from the swarm by the hash. NIP-35 has no tag for a web seed (BEP 19), so an event that wants one must put the URL in a 'tracker' tag or in the content, and a reader cannot tell the two apart by schema — the real event this module was written from does exactly that.
