Struct · module webseed · encoding urlquery · 2 fields · BEP 19 · IRI https://torrent-schema.github.io/WebSeedRequest

What a block request becomes over HTTP: a GET of the right URL with a Range header. Single-file torrents: the URL is the file (a URL ending in '/' has the name appended). Multi-file: the URL is a directory root; name/path components appended; a block that spans two files is two requests.
