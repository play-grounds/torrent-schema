Encoding · module nostr · IRI https://torrent-schema.github.io/nostrEvent

A NIP-01 event: one JSON object with 'id', 'pubkey', 'created_at', 'kind', 'tags', 'content' and 'sig'. The id is the SHA-256 of the canonical serialisation [0, pubkey, created_at, kind, tags, content] with no whitespace; the sig is a BIP-340 Schnorr signature over the id by the key named in 'pubkey'. Hex is lowercase. Tags are arrays of strings whose first element is the tag's name.
