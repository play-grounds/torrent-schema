Module · module tracker · BEP 3, 15, 23, 7, 48 · layer discovery · v0.0.1 · IRI https://torrent-schema.github.io/tracker

How a peer finds other peers for an infohash. A tracker holds no content: it remembers who announced which infohash and answers with some of them. Two transports: HTTP (BEP 3), a GET whose answer is bencoded, and UDP (BEP 15), a fixed binary layout for speed. Both carry the same ideas — announce (here I am, send me peers), scrape (how many are there) — and the same peer list, compact (BEP 23: six bytes a peer) or as dictionaries. Browsers can use neither; WebTorrent's WebSocket tracker is a third transport, modelled later as an overlay.
